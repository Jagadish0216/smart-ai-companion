# Mechanical reference

`MSP3520_Size.pdf` is the unmodified public LCDWiki manufacturer drawing,
downloaded from https://www.lcdwiki.com/res/MSP3520/MSP3520_Size.pdf.
`MSP3520_Size.png` is a rasterization for visual inspection. Drawing label:
MSP3520 V1.0, drawing date 2024-04-17. Dimensions are in millimetres.

In the front portrait view the 14-pin header is at the bottom. The enclosure
uses that edge on the right in landscape front view. The 73.44 mm active region
starts 9.95 mm from the opposite PCB end. It is therefore 2.33 mm left of PCB
centre in this landscape installation. The 84.96 mm LCD outline starts at
6.54 mm and its centre is 0.02 mm right of PCB centre. The glass stack ahead of
the PCB is 1.20 + 2.50 + 0.50 = 4.20 mm. These are reference dimensions, to be
compared with the actual purchased module before printing.
